12 topics worth learning

01 · Foundation

Python for AI

Learn variables, functions, classes, files, packages, exceptions and virtual environments.

Why it matters & what to practise
  • Python is widely used to build data and AI applications.
  • Practise reading a CSV, cleaning values and writing reusable functions.
  • Build: a small data-cleaning script with clear input and output.

02 · Data

SQL, data handling & APIs

Learn SELECT, JOIN, GROUP BY, window functions, JSON, HTTP and REST APIs.

Why it matters & what to practise
  • AI products depend on reliable data and connections to other systems.
  • Practise querying a dataset and calling a public API.
  • Build: a Python script that fetches API data and stores selected fields.

03 · Machine learning

ML fundamentals

Understand features, labels, train/test splits, regression, classification, overfitting and metrics.

Why it matters & what to practise
  • These ideas help you know whether a model has learned a useful pattern.
  • Compare accuracy, precision, recall and F1 for an imbalanced dataset.
  • Build: a baseline classification model and an evaluation report.

04 · Deep learning

Neural networks & deep learning

Learn tensors, layers, activations, loss, optimisers, backpropagation, CNNs and embeddings.

Why it matters & what to practise
  • Deep learning powers many image, speech and language systems.
  • Learn how training changes model weights and how overfitting appears.
  • Build: a small image classifier and explain its errors.

05 · Generative AI

LLMs & tokens

Understand tokens, context windows, transformers, inference, temperature and multimodal inputs.

Why it matters & what to practise
  • These concepts explain what language models can do and where they fail.
  • Compare a short prompt with a structured prompt; inspect hallucinations.
  • Build: a small LLM-powered summariser with input limits and error handling.

06 · Prompting

Prompt design & structured output

Learn instructions, context, examples, constraints, JSON schemas and prompt testing.

Why it matters & what to practise
  • Clear prompts make outputs more predictable, but do not guarantee correctness.
  • Ask for structured JSON and validate it in code.
  • Build: an information extractor that checks required fields.
Prompt engineering guide ↗
07 · Knowledge systems

Embeddings, vector search & RAG

Learn chunking, embeddings, retrieval, reranking, citations and grounded generation.

Why it matters & what to practise
  • RAG retrieves relevant documents before generating an answer.
  • Test whether retrieved passages actually support the answer.
  • Build: a question-answering app over your notes with source links.
RAG learning guide ↗
08 · Agentic AI

AI agents & tool calling

Learn goals, planning, tool calls, state, memory, handoffs, retries and human approval.

Why it matters & what to practise
  • Agents can perform multi-step tasks by selecting and using tools.
  • Start with one safe tool and require approval before external actions.
  • Build: a research assistant that searches trusted sources and cites results.

09 · Connectivity

MCP & agent interoperability

Understand MCP clients, servers, tools, resources, prompts, permissions and agent-to-agent communication.

Why it matters & what to practise
  • MCP standardises how AI applications connect with external context and tools.
  • Inspect what a server can access before connecting it.
  • Build: a local read-only MCP server that exposes sample files.

Evaluation, testing & safety

Learn test datasets, expected answers, groundedness, latency, cost, prompt injection and access control.

Why it matters & what to practise
  • A demo that works once is not a reliable product.

Deployment, monitoring & cloud basics

Learn Git, Docker basics, environment variables, logging, monitoring, authentication and deployment.

Why it matters & what to practise
  • Real applications need repeatable deployment, observability and secure configuration.

  • Build: deploy a small API and log errors without exposing private data.

Practical glossary

AI concepts you will meet in real projects

Not random buzzwords. These concepts help you understand, build, test and explain AI systems.

LLM — Large Language Model

A model trained on large amounts of text to understand and generate language. Used in chatbots, assistants and text workflows.

Token

A chunk of text a model processes. Token limits affect how much context you can send and the cost of a request.

Context window

The amount of input and conversation a model can consider at one time. Important for long documents and multi-step tasks.

Embedding

A numeric representation of meaning. Helps find documents or items that are semantically similar.

Vector database

A system for storing and searching embeddings. Often used to retrieve relevant knowledge for RAG.

RAG

Retrieval-Augmented Generation: retrieve relevant information first, then ask a model to answer using that context.

Fine-tuning

Further training a model on examples to adapt its behaviour. It is not the same as adding live documents.

Inference

Running a trained model to produce an output. In production, consider speed, cost and reliability.

Tool calling

A model requests an application to run a defined function, such as searching a database or calculating a value.

AI agent

A system that uses a model, tools and a control loop to work through a goal. Needs permissions and monitoring.

MCP

Model Context Protocol: a standard for connecting AI applications to external tools and context providers.

API

An interface that lets software systems communicate. AI apps use APIs to call models and other services.

Evaluation

A repeatable way to test whether a model or application performs well on real tasks and edge cases.

Hallucination

An answer that sounds confident but is unsupported or incorrect. Use source checks and evaluation to reduce risk.

Prompt injection

Untrusted content tries to override an AI system's instructions. Treat retrieved text and tool outputs as untrusted input.

Latency

The time a system takes to respond. Important when designing interactive assistants.

Least privilege

Give a tool only the access it needs. Especially important when an AI agent can read files or take actions.

Observability

Logs, metrics and traces that help developers understand failures, speed, cost and system behaviour.

How to use this academy

  1. Start with Python and data if you are new to AI development.
  2. Move through ML, deep learning and LLM fundamentals.
  3. Build one small RAG or agent project rather than collecting many frameworks.
  4. Test your project, document limitations and publish your work.

Learning links point to official documentation or established educational resources. Recheck source documentation before using a framework in production.

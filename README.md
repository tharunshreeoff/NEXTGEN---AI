# NEXTGEN AI

A modern AI learning hub for understanding the latest AI technologies.

## Features
- Interactive 3D-inspired AI hero and learning experience
- World AI Radar with RSS/Atom source feeds
- Agentic AI workflow lab (teaching simulation)
- Searchable AI glossary and learning tracks
- Seven-day learning sprint with local progress tracking
- Responsive, accessible sage-and-ivory design

## Run locally
Open `index.html` in a browser, or serve this directory with any static web server.

## Deployment
GitHub Pages deployment is configured through `.github/workflows/deploy-pages.yml`.
The feed refresh workflow runs daily and updates `data/daily-feed.json` from configured public RSS/Atom feeds.

## Important note
The news radar aggregates publisher feeds. It does not independently verify claims or automatically generate full analysis. Always read and verify the linked original sources.
